我目前是[哈尔滨工业大学](https://www.hit.edu.cn/)软件工程专业博士研究生，导师为[涂志莹](https://homepage.hit.edu.cn/tzy)教授，所在研究中心为[企业与服务智能计算研究中心（ICES）](https://encs.hit.edu.cn/2021/1224/c14651a267021/page.htm)。本科同样毕业于哈尔滨工业大学软件工程专业。

我研究大语言模型智能体，工作重点是让大模型服务在真实应用中更有效、更可靠、更好用。目前在[阿里云通义](https://tongyi.aliyun.com/)从事面向评测的可控数据合成，以及金融领域的模型训练。此前的工作包括大模型服务调用质量，以及大模型智能体的自我改进。具体研究方向包括：

- **大模型应用**：通过自动化流程构建领域数据集，研究可落地的训练与评测方法，并将大模型适配到已部署服务的真实场景（[COLING'25](/publications/#wang2025framework)）。
- **服务调用质量**：在没有标注数据的条件下估计大模型服务表现，并为不同请求选择合适的模型，以提升实际调用质量（[ICSOC'24](/publications/#wang2024plug)、[ARMS](/publications/#wang2026arms)）。
- **自我改进**：让大模型智能体发现尚未调用的能力、修复失败动作，并在交互中持续改进自身（[ICWS'25](/publications/#wang2025unlocking)、[SkillAudit](/publications/#gao2026skillaudit)）。
- **服务文档**：自动评测并生成 Web API 服务文档中的细粒度描述（[IEEE TSC](/publications/#wang2026detail)）。
